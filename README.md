# Superstore Sales Analysis

## Project Overview
This project analyzes the Superstore dataset using Excel, SQL Server, and Power BI to answer key business questions and provide business insights.

## Business Questions
- Which category generates the highest profits?
- Do large discounts lead to increased profits?
- Which sub-categories achieve high sales but low profits?
- Which ship mode achieves the highest profit?
- What is the relationship between discount and profit?
- Which states are the most profitable?
- Which segment is the most profitable?
- What is the sub-category classification based on profitability?

## Tools Used
- Excel (Power Quary)
- SQL Server
- Power BI
  
📊 Data Cleaning
- Removed duplicates.
- Filled missing values.
- Changed data types.
- Formatted discount as percentage.

🔍 Key Insights
- Technology category generated the highest profit.
- Some products have high sales but low profit.
- Discounts impact profitability
- Higher discounts generally reduced profitability

💡 Recommendations
 - Reduce discounts.
 - Review shipping costs.
 - focuse on high-profit product categories
